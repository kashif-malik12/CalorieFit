# Privacy Policy Draft

## CalorieFit Privacy Policy

Last updated: 2026-04-02

CalorieFit is a local-first calorie and nutrition tracking app.

## What data the app handles

CalorieFit allows users to create and store:
- Food entries
- Meal templates
- Nutrition targets
- History and retention preferences

This information is stored locally on the user's device.

## Data stored on device

The app stores app data locally using on-device storage and SQLite.

Local data may include:
- Foods created or imported by the user
- Logged meals and nutrition history
- Template data
- Macro target settings
- Retention settings

## Internet access

CalorieFit may use internet access for optional online food search.

Current online search behavior:
- User-entered food search terms are sent to the USDA FoodData Central API.
- Search results are used to help fill nutrition values or log food manually.
- This feature is optional.

USDA FoodData Central:
- https://fdc.nal.usda.gov/

## Accounts

CalorieFit does not currently require a user account.

If account-based cloud sync is added in a future release, this privacy policy must be updated before that version is published.

## Data sharing

CalorieFit does not sell user data.

At the current local-first stage, app data is not uploaded to a CalorieFit cloud backend because no app backend is currently active.

Optional USDA search sends search queries to USDA only when the user uses that feature.

## Data retention and deletion

Users can:
- Delete local foods, templates, and log entries inside the app
- Change retention settings for stored history
- Uninstall the app to remove locally stored app data from the device

## Security

CalorieFit relies on platform storage protections provided by the operating system.

If network features are used, requests are sent over HTTPS where supported by the remote service.
