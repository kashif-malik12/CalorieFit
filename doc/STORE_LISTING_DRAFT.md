## App Name

## Short Description

Track calories, meals, and macros with a simple local-first food diary.

## Full Description

CalorieFit is a simple calorie and nutrition tracker built for fast daily logging.

Use it to:
- Log meals by category
- Track calories, protein, carbs, and fat
- Save your own foods
- Reuse meal templates
- Set daily macro targets
- Browse a built-in food and template library
- Search online food data when needed

Key features:
- Local-first food logging
- Custom foods and meal templates
- Serving size presets
- Daily history and progress tracking
- BMI and calorie tools
- Optional online nutrition search

CalorieFit is designed for people who want a lightweight food diary without unnecessary complexity.
